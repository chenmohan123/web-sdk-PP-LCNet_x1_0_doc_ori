# 0.2.0 发布说明

发布日期：2026-09-07。npm 包：`web-sdk-pp-lcnet-x1-0-doc-ori@0.2.0`。本次属于单 SDK 的标准整改与发布治理，不改变模型权重。

## 主要变化

- 增加模型下载、缓存读取、完整性校验的独立计时，以及来源于成功会话的请求/实际后端、执行模式、运行时版本。
- 增加当前模型与本 SDK 全部模型的缓存清理和容量估计，使用结构化缓存身份，避免 ID/版本包含斜杠时碰撞，并防止对应模型的清理前下载重新写回缓存。
- Demo 展示缓存、运行信息与标准耗时，按当前来源及实际加载模型确定清理范围，支持双语说明与四种方向样例。
- 增加可独立安装的 Vanilla TypeScript/Vite 示例；CI 使用当前 SDK tarball 在临时目录构建并执行真实浏览器推理、取消和失败恢复。
- 发布流程仅接受版本标签推送，核对 package、manifest、更新日志及 `origin/main` 归属，使用 GitHub OIDC 可信发布和 npm provenance。

## 模型、许可与默认资产

模型来自 [PaddlePaddle/PP-LCNet_x1_0_doc_ori_onnx](https://huggingface.co/PaddlePaddle/PP-LCNet_x1_0_doc_ori_onnx)，模型和 SDK 均使用 Apache-2.0。模型 ID 为 `PP-LCNet_x1_0_doc_ori`，版本为 `1.0.0`；默认 `official-fp32` 资产是 FP32 ONNX、opset 7、1,687,613 个参数。

包内默认包含 `dist/models/manifest.json` 与 `dist/models/inference.onnx`。模型大小为 6,788,069 字节，SHA-256 为 `af9a0a4f317ff0709ce752067807f819cb15d883f8ecad89f28df1c6ee2d9c92`。无法暴露包内资源的打包器按现有逻辑回退到项目 Pages；Demo 默认选择 ModelScope，也可显式选择 Hugging Face。WASM 资源默认来自 ONNX Runtime Web CDN，可由宿主配置资源路径。

## 后端、升级与边界

运行时仍为 `onnxruntime-web@1.27.0`，支持显式 `wasm`、`webgpu` 及 main/worker 模式，不静默切换后端。此次 Windows 无头 Chromium 验证实际 WASM 推理；没有可用 GPU 适配器，WebGPU 用例按环境跳过，不新增 WebGPU 或 NPU 兼容性承诺。

旧 `createDocOrientation()`、`detect()`、`detectBatch()`、`rotate()`、`clearModelCache()` 调用保持可用，旧 `backend` 与 `downloadMs` 字段保留。使用自定义 Worker URL 的宿主须同步部署 0.2.0 的 Worker 产物，以便回传新版运行信息。

缓存容量是去重后的模型数据字节数，不是浏览器配额或实际磁盘占用。清理不会释放已加载推理会话；防止旧下载回填的同步边界是同一 SDK 模块与 JavaScript 上下文，跨标签页由宿主协调。`actualBackend` 说明成功会话的执行提供程序，不表示每个算子都运行于 GPU。

发布验证证据见 [2026-09-07 的 0.2.0 验证报告](../reviews/2026-09-07-release-0.2.0.md)。历史标准整改报告保留原验证版本；远程 CI、npm 与 Pages 的实际发布状态需由本次发布任务核实。
