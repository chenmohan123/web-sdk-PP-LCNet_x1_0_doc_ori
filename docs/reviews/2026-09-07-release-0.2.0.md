# 2026-09-07 LCNet 0.2.0 发布验证

本次属于单 SDK 层，发布包为 `web-sdk-pp-lcnet-x1-0-doc-ori@0.2.0`；模型仍为 `PP-LCNet_x1_0_doc_ori@1.0.0`，权重、模型 SHA-256 和 ONNX Runtime Web `1.27.0` 未变。标准整改的历史过程保留在 [原报告](2026-09-07-standard-remediation.md)，本报告记录最终发布版本的重新验证。

- SDK package、sdk-manifest、npm 安装命令、CDN 引用、Vanilla 示例与 Demo 版本断言同步为 0.2.0，历史版本和审查报告未改写。

## 消费者与浏览器证据

`scripts/verify-vanilla-package.mjs` 使用 `pnpm pack` 生成带有模型、Worker、类型及浏览器入口的 0.2.0 tarball，将示例复制到本次独立临时目录后，仅在该副本把 npm 依赖替换为 tarball。安装不依赖 0.2.0 已发布到 npm，正式 `examples/vanilla-vite/package.json` 的内容在验证前后完全一致，临时目录完成后清理。正式示例不提交旧版本锁文件，独立安装使用 `pnpm install`。

浏览器确认安装包版本与当前 SDK 相同，真实推理返回 `orientation: 90`、`requestedBackend: wasm`、`actualBackend: wasm`，并具有独立 `modelDownloadMs`、`modelCacheReadMs` 和 `integrityMs`。取消后恢复操作；模拟模型清单 500 失败后，恢复网络并再次完成真实 90° 推理。

生产 Demo 覆盖 ModelScope/Hugging Face 两种来源选择、实际加载清单版本变化后的缓存身份、当前清理保留其他版本、错误与恢复、IndexedDB 禁用后的内存降级，以及正确旋转文档。模型请求通过路由固定为本地官方模型字节，验证完整 SDK/WASM 链路，不能据此宣称远程模型站点持续可用。

已检查 `node_modules/.cache/release-0.2.0-production/` 中的移动端成功截图和 `node_modules/.cache/vanilla-review/success.png`；图片与控制项可见，移动端没有横向溢出。测试为核对实际模型身份在生产截图中使用了清单版本 `2.0.0` 的固定样本，此值不是本次发布模型版本。证据目录被 Git 忽略，可通过上述命令复现。
