# PP-LCNet_x1_0_doc_ori model

This directory contains the official ONNX export from PaddlePaddle's
`PP-LCNet_x1_0_doc_ori_onnx` repository. The model is an orientation classifier
with four labels: `0`, `90`, `180`, and `270` degrees.

Source: https://huggingface.co/PaddlePaddle/PP-LCNet_x1_0_doc_ori_onnx
